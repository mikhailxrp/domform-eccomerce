# Phase 1 — Каталог и карточка товара

## Цель

Гость открывает каталог по категориям, фильтрует (цена / категория /
цвет / «В наличии») без перезагрузки страницы, сортирует, листает
страницы, ищет с подсказками, открывает карточку товара и переключает
Варианты (материал/механизм → цена и срок изготовления; цвет → только
фото) — на данных из сидов, без Панели управления — `FR-CAT-001…008`,
`FR-CAT-009` (без иконки «в избранное»), `FR-CARD-001…005, 007…009`,
`FR-SRCH-001…004`, отображение `BR-004`.

Не входит (перенесено ранее, `ADR-017`): `FR-CAT-010` (фильтр «Со
скидкой» → Фаза 6), `FR-CARD-006` (отзывы на карточке → Фаза 6), иконка
«в избранное» на мини-карточке (→ Фаза 7). Quick View из темы ни одним
`FR-*` не требуется — не строится.

## Статус

🔄 В работе

## Решения фазы

- **Схема (`FR-CAT-008`, `FR-CARD-005`)** — две дыры, не закрытые ни
  одним ADR: у `categories` нет `description`, у `products` нет места
  под «таблицу характеристик и размеров». Закрываются Таском 1 по
  образцу Таска 1 Фазы 0: `categories.description TEXT NULL` + новая
  таблица `product_specs` (`product_id`, `name`, `value`, `sort_order`)
  на уровне Товара (материал/механизм уже на Варианте; размеры/форма —
  общие для Товара). Фиксируются в `database.md` и `planning-log.md`
  (`ADR-029`, `ADR-030`) внутри Таска 1, не задним числом.
- **Кнопка «В корзину» (`FR-CARD-001`, `FR-CAT-009`)** — корзина
  появится в Фазе 2. В Фазе 1 рендерится форма `POST /cart/add`
  (`variant_id`, `color`, `quantity`) и клиентская блокировка «выберите
  вариант» — критерий приёмки `FR-CARD-001` проверяется уже сейчас;
  обработчик маршрута — первый таск Фазы 2. Единственная «заглушка»
  фазы, того же рода, что иконка корзины «0» в шапке из Фазы 0.
- **Поиск и `FULLTEXT` (`FR-SRCH-001/002`)** — `innodb_ft_min_token_size`
  = 3 на shared-хостинге не поменять, а подсказки нужны с 2 символов.
  Запрос ≥ 3 символов — `MATCH ... AGAINST ('слово*' IN BOOLEAN MODE)`
  по `products(name, description)`; 2 символа — префиксный `LIKE 'xx%'`
  по `products.name` (не `%xx%`, ≤ 200 строк). Материал/цвет —
  `LIKE 'q%'` по `product_variants.material` / `variant_images.color`.
  Осознанное отступление от правила `database.md` — фиксируется ADR в
  Таске 5.
- **Фильтры без перезагрузки (`FR-CAT-001`)** — не отдельный JSON API,
  а тот же `CatalogController`: при `X-Requested-With: fetch` отдаёт
  только фрагмент (сетка + пагинация), JS — `fetch` +
  `history.pushState` / `popstate`. Один шаблон карточки; без JS страница
  фильтруется обычным GET-сабмитом формы.
- **Фото в сидах** — пути на изображения темы
  `public/assets/images/product/*.jpg`; реальная загрузка фото в
  `public/uploads/products/` — Фаза 4 (`FR-ADM-001`).
- **Цена на мини-карточке** — «от X ₽» = минимальная цена активных
  Вариантов; фильтр по цене отбирает Товар, если хотя бы один активный
  Вариант попадает в диапазон. Цвета для фильтра — `DISTINCT color` из
  `variant_images`. «Новизна» = `products.created_at DESC`.
- **Вид плитка/список (`FR-CAT-006`)** — `sessionStorage` (ровно
  «в пределах сессии браузера»), не cookie и не серверная сессия.
- **Константы** — товаров на страницу: 12; подсказок поиска: 5;
  минимальная длина запроса: 2 — именованные константы в
  `config/config.php`, не magic numbers.
