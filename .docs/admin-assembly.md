# Сборка страниц админки

Страницы, которых нет готовыми в шаблоне — собираются из указанных
блоков на этапе разработки (`phase-init`/`task-init`), не сейчас.
Эта команда только фиксирует план, не пишет код.

Источники:
- `00-input/admin/*.html` + `00-input/admin/assets/` — куратированный
  набор страниц шаблона Valex, отобранных под требования `FR-ADM-*`/
  `FR-MGR-*` этого проекта (аналог `00-input/design/` для витрины).
  Пути на ассеты внутри уже выправлены под плоскую раскладку (`assets/…`,
  не `../assets/…`) — файлы открываются в браузере как есть.
- `00-input/admin-template/html/…` — полный исходный набор шаблона
  (не куратированный), используется только как справочный материал для
  страниц ниже, помеченных «справочно» — эти файлы **не скопированы**
  в `00-input/admin/`, потому что сами не становятся рабочей страницей
  (см. `page_role`/`status: kept-as-reference` в
  `admin-pages-manifest-classified.json`).

## Не покрыто ни готовой, ни недостающей страницей — открытые вопросы

**Q-DEV-006. Закрыт (2026-09-19).** `FR-MGR-002` (создание заказа вручную
по звонку/WhatsApp) не имел соответствия ни в
`admin-pages-manifest-classified.json`, ни в `admin-missing-pages.json`.
Ближайший по духу паттерн — та же форма, что уже назначена для «Формы
товара» (`mail-compose.html`), но состав полей (выбор Товара/Варианта,
контакт/привязка существующего Покупателя по телефону, адрес доставки
или отметка самовывоза — правило 1 `FR-MGR-002`) исходными материалами
не был зафиксирован. Решено в Таске 5 Фазы 4: собственная разметка
`/admin/orders/create` (телефон → «Найти» → привязка Покупателя либо
гостевые контакты, получение/оплата, предоплата, позиции через
`variant-picker`), не готовая страница шаблона — см. `phase-4.md`,
Таск 5, и `tz-coverage.md`.

**Q-DEV-007.** `FR-ADM-003` (управление контентом статических страниц и
баннерами Главной) не имеет соответствия ни в одном из двух источников.

или `mail-compose.html`) плюс отдельный блок редактирования слайдера
баннеров (изображение/текст/ссылка, `FR-HOME-001`) — конкретный
`build_from` не зафиксирован. Решается на `phase-init`/`task-init`
Фазы 8.

**Q-DEV-008.** `FR-ADM-007` правило 4 (технические настройки сайта —
секреты интеграций, окружения, домен) не размечается сейчас: сам ТЗ
явно откладывает состав этого экрана до закрытия `Q-032` (раздел 16,
`NFR-OPS-*`). Экран управления сотрудниками/ролями (та же `FR-ADM-007`,
но правила 1–3) от этого не зависит и уже размечен выше через
`userlist.html`/`editprofile.html`.
