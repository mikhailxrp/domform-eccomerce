# ДомФорм — интернет-магазин мебели под заказ

Портфолио-проект: полноценный интернет-магазин для магазина мебели
«ДомФорм» (Краснодар) — каталог с вариантами товара, корзина, оформление
заказа, панель менеджера, админ-панель, личный кабинет и встроенные
ИИ-помощники. Мебель изготавливается под заказ, поэтому сайт закрывает
витрину и первый шаг покупки, а ткань, размер и доставку менеджер
согласовывает с клиентом по телефону.

Проект разработан по методологии SDD (spec-driven development): сначала
ТЗ → PRD → схема БД → фазы → таски, и только потом код. Вся документация
проектирования лежит в репозитории рядом с кодом.

## Что умеет магазин

### Покупатель (в том числе без регистрации)
- **Каталог** — фильтры по цене, категории, цвету, «Выставочный образец»,
  «Со скидкой»; сортировка; пагинация; поиск с подсказками.
- **Карточка товара** — выбор Варианта (материал / цвет / механизм) с
  собственным артикулом, ценой и сроком изготовления; галерея фото по
  цветам; характеристики; отзывы; похожие товары.
- **Корзина и оформление заказа** — гостевой чекаут без регистрации, выбор
  способа получения (доставка / самовывоз из шоурума) и оплаты
  (картой на сайте / наличными / переводом).
- **Личный кабинет** — история заказов, сохранённые адреса, избранное,
  личные данные.
- **Авторизация** — email + пароль, обязательный телефон при регистрации,
  «Запомнить меня», восстановление пароля по email.
- **Статические страницы** — контакты, о компании, шоурум с картой,
  доставка и оплата, возврат и гарантия, юридические документы.

### Менеджер
- Единый список заказов с сайта и по звонку/WhatsApp, фильтр по статусу.
- Смена статуса заказа по жизненному циклу
  «Новый → Подтверждён → В производстве → Готов к отгрузке → В доставке →
  Доставлен» (или «Отменён») — только через валидируемый переход.
- Ручное создание заказа по звонку, правка состава до запуска в
  производство.
- Клиенты с поиском по телефону.
- **Выставочный образец** — резерв по первой предоплате, защита от
  двойного резерва на уровне БД (`UNIQUE` на generated column).
- Возврат по звонку, расчёт гарантии 18 месяцев от даты доставки.

### Администратор
- Всё, что Менеджер, плюс: товары и варианты, категории (2 уровня),
  скидки на вариант, модерация отзывов, отчёты по продажам за период,
  контент страниц и баннеры главной, учётные записи сотрудников и их
  блокировка.

### ИИ-помощники
- Разбор характеристик из текстового описания товара.
- Генератор черновика описания.
- Консультант в чате по доставке / оплате / возврату.
- Подбор товара диалогом.
- Все сценарии покупки работают и при недоступности ИИ-провайдера.

## Объём портфолио-версии

Два модуля намеренно упрощены — цель проекта показать работающий магазин
и встраивание автоматизаций, а не провести реальные деньги:

| Модуль | Что в портфолио |
|---|---|
| Онлайн-оплата | Кнопка «Картой на сайте» ведёт на страницу-заглушку без списания; оплату отмечает менеджер вручную. Реальная интеграция с ЮMoney и фискализация (Атол) не подключаются |
| ИИ-консультант | Реальный вызов языковой модели, но правила доставки/оплаты зашиты в системный промпт, а не читаются со страниц сайта |

Остальное — без упрощений.

**Известное ограничение хостинга:** на боевом shared-хостинге (Beget)
Cloudflare, стоящий перед `openrouter.ai`, блокирует исходящие запросы
с IP хостинга (`403 Access denied by security policy`) — судя по всему,
репутация IP-диапазона, а не что-то специфичное для проекта. Из-за
этого недоступны «Разбор характеристик» и «Генератор описания» (оба —
класс задачи `anonymous`, провайдер OpenRouter/Claude); все сценарии
покупки при этом работают штатно (`AC-06`) — помощники просто
показывают «недоступно», как и при любом другом отказе провайдера.
Консультант в чате (класс `user_input`, YandexGPT — российская
инфраструктура, не за Cloudflare) на этом хостинге работает без
проблем. Локально/на хостинге без такой блокировки оба помощника
работают одинаково — подробности диагностики в `.docs/dev-log.md`,
23.09.2026.

## Стек

| Слой | Технология |
|---|---|
| Backend | PHP 8.x, самописный роутер, без фреймворков и ORM |
| БД | MySQL 8, PDO с prepared statements |
| Frontend | Bootstrap 5 + jQuery 3.5 (из купленной темы), без сборщиков |
| Графики | Chart.js |
| Авторизация | PHP Sessions + bcrypt, CSRF-токены, rate-limit |
| Тесты | PHPUnit (unit-тесты ядра и чистой логики) |
| Деплой | Любой shared-хостинг с Apache (`.htaccess`) |

Все сторонние CSS/JS хранятся локально — сайт не зависит от CDN.

## Архитектура

```
public/           document root, единственная точка входа (index.php)
public/assets/    CSS/JS/изображения темы
public/uploads/   фото товаров (PHP там не выполняется)
src/Core/         Router, Database, Request, Logger, helpers
src/Controllers/  обработка запросов — без SQL
src/Models/       только SQL, возвращают массивы
src/Views/        только HTML, весь вывод экранирован
src/Services/     email, файлы, ИИ-провайдер, внешние API
config/           routes.php, config.php
database/         install.php (схема), seed.php (первый администратор)
storage/logs/     логи — вне document root
tests/Unit/       PHPUnit
.docs/            PRD, схема БД, спеки модулей, фазы, журнал решений
```

Ключевые решения схемы: Товар → Варианты (артикул/цена/срок у варианта,
не у товара), фото привязаны к цвету варианта, M:N Товар↔Категория,
снэпшот позиции в заказе, резерв выставочного образца с защитой от гонки.
Подробно — `.docs/database.md`, обоснования — `.docs/planning-log.md`.

## Запуск локально

```bash
git clone https://github.com/mikhailxrp/domform-eccomerce.git
cd domform-eccomerce
composer install                # PHPUnit, только для разработки
cp .env.example .env            # заполнить DB_*, ADMIN_*, MAIL_DRIVER=log
php database/install.php        # создать таблицы
php database/seed.php           # первый администратор из ADMIN_* в .env
composer test                   # unit-тесты
```

Document root веб-сервера — папка `public/`. Для OSPanel/XAMPP достаточно
положить проект в директорию сайтов: корневой `.htaccess` перенаправит всё
в `public/`.
